Spack is a package manager for [supercomputers], Linux, macOS, and Windows. It makes installing scientific software easy. Spack isn't tied to a particular language; you can build a software stack consisting of Python or R packages, link to libraries written in C, C++, or Fortran, easily [swap compilers], and target [specific microarchitectures]. Learn more [here][about].
